Place PNG, JPG or JPEG images in this folder, then restart the game.
Right-click a LinkWindow and select the image filename in TrueWindow's display source setting.
Keep filenames unchanged to preserve saved selections.

このフォルダーにPNG・JPG・JPEG画像を入れて、ゲームを再起動してください。
窓を右クリックし、TrueWindowの表示元から画像のファイル名を選べます。
選択を保持するには、ファイル名を変更しないでください。
