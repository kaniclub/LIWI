# LinkWindow（LIWI）

1マスの壁掛け窓を上下左右につなげて、ひとつの窓として使えるMODです。TrueWindowと連携し、窓の中に外の景色を表示します。

現在のバージョン：**1.0.0**。変更点は[更新履歴](CHANGELOG.md)を参照してください。

## できること

- 隣接する窓をつなげ、接続した窓全体の見た目をまとめて設定。
- 外枠を木・鉄・枠なしから選択。
- サイズを大・中から選択。
- 四隅の上・下・左・右に当たる8か所を、それぞれ角形・丸形に設定。
- 縦・横の格子本数を個別に調整。0本にすると、その方向の格子を非表示。
- バニラの窓に馴染む木枠・鉄枠のデザイン。
- 窓の形やサイズに合わせて、周囲の壁紙を表示。

## 必要環境

- Stardew Valley 1.6
- SMAPI 4.0以降
- [TrueWindow](https://github.com/kaniclub/TWIN) 1.0.6以降と、その必須MOD
- Generic Mod Config Menu（任意）

## 導入

1. 必要なMODを導入します。
2. ゲームを終了し、LinkWindowの配布ZIPを展開して、`LinkWindow`フォルダーをゲームの`Mods`フォルダーへ配置します。
3. SMAPIからゲームを起動します。

## 入手・使い方

通常の**家具カタログ**から「つながる窓（LinkWindow）」を無料で入手できます。

壁に窓を設置し、上下左右に並べると自動的につながります。

設置した窓にカーソルを合わせて**F6**を押すと、接続した窓全体の設定画面が開きます。変更はすぐに反映され、セーブデータに保存されます。編集中の窓は設定画面を開いている間だけ強調表示されます。

## 窓の設定

- **外枠**：木・鉄・枠なし。
- **サイズ**：大・中。中は幅と高さが大の75%になり、周囲に壁紙が見えます。
- **形**：中央のプレビューを囲む8個のボタンで、それぞれ角形・丸形を切り替えます。すべて丸形にすると円形・楕円形になります。
- **格子**：縦・横それぞれのマイナス・プラスボタンで本数を調整します。縦だけ・横だけ・格子なしにもできます。

外景の位置や拡大率などは、窓を**右クリック**してTrueWindowの設定画面から変更します。外景の設定は、同じロケーション内の窓で共有されます。

## 好きな画像を表示する

1. `Mods/LinkWindow/images`フォルダーに、PNG・JPG・JPEG画像を入れます。
2. ゲームを再起動します。
3. 設置した窓を右クリックし、TrueWindowの「表示元」から画像のファイル名を選びます。

複数の画像を追加できます。`images`直下の画像が対象です。選択した画像はセーブデータに保存されるため、ファイル名はそのままにしてください。

表示位置や拡大率はTrueWindowの設定で調整できます。選んだ画像は同じロケーション内のTrueWindow対応窓で共有されます。画像を削除した場合や読み込めない場合は、外景表示に戻ります。

## 設定キーの変更

Generic Mod Config MenuでLinkWindowを選び、「窓の設定を開くキー」を変更して保存してください。複数キーの組み合わせにも対応しています。

Generic Mod Config Menuを導入していない場合は、MODフォルダーの`config.json`から変更できます。

## 注意事項

- 設置範囲は1マス単位です。丸形や中サイズの透明部分にも、別の家具は重ねられません。
- L字などの形にも接続できます。形と格子は接続グループ全体を囲む長方形が基準になります。
- 格子本数に固定の上限はありませんが、細かな格子の表示には画像の解像度による限界があります。
- 外景の準備中は青いガラスが表示されます。
- 窓の設定を編集できるのはホストのみです。マルチプレイでの動作とコントローラーのみでの操作は未検証です。

## 開発

.NET 6 SDK、Stardew Valley、SMAPIが必要です。

```powershell
dotnet build .\LIWI.sln -c Release
dotnet run --project .\tests\LinkWindow.Checks\LinkWindow.Checks.csproj
```

配布ZIPは`releases`フォルダーに出力されます。

ローカル環境へ導入する場合は、ゲームを終了して`Install.ps1`を実行します。隣に`TWIN`プロジェクトがある構成を想定しており、必要に応じてTrueWindowもビルド・導入します。
